# LGFX_Fonts

Externally managed fonts for [LovyanGFX](https://github.com/lovyan03/LovyanGFX) / [M5GFX](https://github.com/M5Stack/M5GFX).

## Requirements

- LovyanGFX >= 1.2.20
- M5GFX >= 1.2.20


## Usage

```cpp
#include <LovyanGFX.hpp> // or <M5GFX.h>
#include <LGFX_Fonts.hpp>
```
